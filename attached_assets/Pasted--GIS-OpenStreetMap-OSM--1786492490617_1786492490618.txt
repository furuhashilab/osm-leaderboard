あなたは優秀なフロントエンドエンジニアであり、GIS（地理情報システム）およびウェブ開発の専門家です。
以下の要件に従って、OpenStreetMap (OSM) コントリビューターの編集実績を可視化する「OSMリーダーボードウェブアプリケーション」を構築してください。

## 1. プロジェクト概要
OSMのアカウント名リストを記述したYAMLファイルを読み込み、各アカウントの編集実績を収集・集計してランキング形式で表示する静的ウェブサイトを作成します。
バックエンドサーバーは持たず、GitHub Pages でホスティングすることを前提とし、すべての処理（HTML/CSS/JSによるAPIのフェッチ、集計、UI描画）はクライアントサイド（ローカル環境含む）で完結するようにしてください。

## 2. 技術スタックと環境設定
* **フロントエンド:** HTML5, CSS3, Vanilla JavaScript (または軽量なフレームワーク/ビルドツールを使用しないVue/React CDN版。指定がなければ Vanilla JS で実装)
* **データソースファイル:** YAML (`js-yaml`等のライブラリを使用してパース)
* **マップライブラリ:** MapLibre GL JS (最新版)
* **地図タイル:** OpenFreeMap (ベクトルタイル)。3D建物データを立体的に表現(extrusion)するように設定。
* **データ取得:** Overpass API または OSM Changeset API をクライアントサイドから非同期でフェッチして集計。
* **インフラ:** GitHub Pages (完全な静的サイト、PWA対応)

## 3. 機能要件
### 3.1 評価軸と集計 (HDYCを参考)
各ユーザーについて、以下の指標を取得・集計してください。
* 建物の新規入力数 (building=*)
* 建物の修正数
* wheelchair マッピングの成果 (wheelchair=* などの追加/修正)
* 指定ハッシュタグを含むチェンジセットの集計
  * デフォルトのハッシュタグ設定: `#furuhashilab`, `#DRONEBIRD`, `#PLATEAU`

### 3.2 期間フィルタリング機能
UI上にタブまたはセレクトボックスを設け、以下の5パターンの期間で実績を切り替えて表示・比較できるようにしてください。
1. Daily (過去24時間)
2. Weekly (過去7日間)
3. Monthly (過去30日間)
4. Yearly (過去365日間)
5. All Time (全期間)

### 3.3 リーダーボードUIとデザイン
* 全アカウントの比較結果をテーブル、またはカードベースのリストで表示。
* **TOP3の強調表示:** 1位、2位、3位のユーザーは、王冠アイコン、ゴールド/シルバー/ブロンズのカラーリング、アニメーションなどを活用し、視覚的に派手で目立つようにデザインしてください。
* マップ連携: リスト内のユーザーをクリックすると、そのユーザーが直近で編集したエリア（または特定の代表的な場所）を MapLibre の地図上でハイライト、またはフライ・トゥ (flyTo) させるようなUIを実装してください。

### 3.4 PWA対応
* スマホでもアプリのように利用できるよう、PWA (Progressive Web App) として機能させてください。
* `manifest.json` と、キャッシュを利用してオフラインでも最低限動作する `service-worker.js` を作成してください。
* レスポンシブデザインとし、モバイル端末での表示を最適化してください。

## 5. 出力と実装のステップ
以下のステップで段階的にコードを生成し、ファイルを出力してください。
1. **プロジェクト構造の提案:** 作成するファイル群 (`index.html`, `style.css`, `app.js`, `users.yaml`, `manifest.json`, `sw.js` など) のリストを提示してください。
2. **YAMLパーサーとデータフェッチ基盤:** Overpass API等を利用してOSMデータを取得するロジック (JavaScript) を実装してください。※APIの負荷やCORSに配慮した設計にすること。
3. **マップの実装:** MapLibre GL JS と OpenFreeMap を用いた3D建物表示を含む地図コンポーネントを実装してください。
4. **UIとPWAの実装:** TOP3の派手なデザインを含むリーダーボードUIと、PWA対応のファイル群を実装してください。

コードは最新の標準に準拠し、ローカル環境（VS CodeのLive Serverなど）ですぐに動作する完全なものを提供してください。
